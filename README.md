# Sudoku

A responsive Sudoku web game with three difficulty levels, unique-solution puzzles, pencil notes, hints, undo, pause, a timer, and automatic browser-local progress saving.

## Play locally

Open `index.html` in a modern browser. No installation or build step is required.

## Controls

- Select a square and enter a number using the keypad or keys 1–9.
- Use arrow keys to move between squares.
- Press N to toggle notes.
- Press Backspace or Delete to erase.

## Files

- `index.html`: page structure
- `style.css`: responsive styling
- `app.js`: puzzle generation, validation, and game interactions

Fonts load from Google Fonts. Game progress is stored in localStorage on the current browser.
